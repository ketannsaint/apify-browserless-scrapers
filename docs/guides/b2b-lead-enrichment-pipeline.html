Recipe 1: Detect Target SaaS Companies Hiring + Enrich Their Domains (TypeScript)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: process.env.APIFY_TOKEN });

// 1. Pull live ATS openings directly from Greenhouse, Ashby, Lever & remote boards
const jobsRun = await client.actor('leopoldsaint/career-site-jobs-scraper').call({
    searchQueries: ['growth', 'marketing', 'engineer'],
    companyBoards: ['greenhouse:stripe', 'ashby:openai', 'lever:spotify'],
    includeRemoteBoards: true,
    minSalaryUsd: 120000,
    maxJobs: 50,
});
const { items: jobs } = await client.dataset(jobsRun.defaultDatasetId).listItems();

// 2. Check which target domains are actively spending on Google Ads
const adsRun = await client.actor('leopoldsaint/google-ads-transparency-scraper').call({
    domains: ['hubspot.com', 'shopify.com'],
    region: 'US',
    maxAdsPerTarget: 10,
    maxTotalAds: 20,
});
const { items: ads } = await client.dataset(adsRun.defaultDatasetId).listItems();

// 3. Enrich any prospect domain list at a flat per-website rate (never billed per page!)
const contactRun = await client.actor('leopoldsaint/website-contact-email-scraper').call({
    websites: ['https://apify.com', 'https://basecamp.com', 'https://linear.app'],
    maxPagesPerDomain: 4,
    onlyWithEmail: true,
    includeTechStack: true,
});
const { items: contacts } = await client.dataset(contactRun.defaultDatasetId).listItems();

console.log({ jobs: jobs.length, activeAds: ads.length, enrichedContacts: contacts.length });

Recipe 2: Clay / n8n / Make Flat-Rate Website Enrichment (1 HTTP Call)

If you enrich lists coming out of Google Maps, directories, or LinkedIn company exports, per-page contact scrapers can burn your budget when a website has 40 nested pages.

Instead, hit the synchronous flat-per-domain endpoint directly from Clay, n8n, or Make:

POST https://api.apify.com/v2/acts/leopoldsaint~website-contact-email-scraper/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN
Content-Type: application/json

Payload:

{
    "websites": ["https://apify.com", "https://basecamp.com", "https://linear.app"],
    "maxPagesPerDomain": 4,
    "onlyWithEmail": true,
    "includeTechStack": true
}

What you get back for each domain:

  • bestEmail (ranked to prefer domain-matching non-noreply addresses) + emailDomainMatch: true/false
  • Split personalEmails vs roleEmails
  • phones, 10 clean social profile URLs (linkedin, twitter, instagram, facebook, tiktok, youtube, github, etc.), Schema.org address, and techStack
  • Non-2xx error pages (404/500) and domains without an email (when onlyWithEmail: true) are skipped and never billed.

Recipe 3: Shopify Agency Weekly Lead Feed (Zero Duplicate Charges)

For Shopify email/SMS, CRO, retention, or paid-social agencies:

import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])

run = client.actor("leopoldsaint/shopify-active-ads-lead-finder").call(run_input={
    "niche": "pet supplements",
    "country": "US",
    "serviceFocus": "email_sms",
    "requireEmail": True,
    "rememberDeliveredLeads": True,
    "maxLeads": 10,
})

for lead in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(lead["domain"], lead["email"], lead["fitScore"], lead["missingStack"])

Because rememberDeliveredLeads: true persists previously delivered domains across runs, you can schedule this weekly and only pay for brand-new verified Shopify advertisers entering your niche.
