How to Build a Fast YouTube Search -> Transcript -> Comments AI Research Pipeline Without Puppeteer

Most tutorials for building a YouTube AI research or RAG pipeline start by spinning up Playwright or Puppeteer, waiting 25 seconds per video, burning through residential proxies, and paying extra add-on fees just to filter by upload date.

When you only need structured data — video metadata, full timestamped transcripts/SRT, top comments with reply threads, and creator contact details — launching a full Chromium browser is pure overhead.

In this guide, I'll walk through a pure HTTP / InnerTube pipeline running on 512 MB containers that finishes a multi-video search + transcript + comments run in 4–10 seconds and costs roughly $0.002–$0.003 per item (under Apify's $5 monthly free tier, you can process 1,500+ videos/transcripts a month for $0).

Option 1: End-to-End TypeScript / Node.js Pipeline

Install the official client:

npm install apify-client

Run a search for recent videos in your niche, pull full transcripts for the top performers, and extract audience pain-point comments mentioning pricing or alternatives:

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: process.env.APIFY_TOKEN });

// 1. Discover high-view videos published in the past month (no upload-date surcharge)
const videoRun = await client.actor('leopoldsaint/youtube-video-channel-scraper').call({
    searchQueries: ['ai agents workflow'],
    uploadDate: 'month',
    sortBy: 'viewCount',
    maxTotalVideos: 10,
    includeVideoDetails: true,
    minViews: 5000,
});
const { items: videos } = await client.dataset(videoRun.defaultDatasetId).listItems();
const videoUrls = videos.filter((v) => v.hasCaptions).map((v) => v.videoUrl);

// 2. Pull clean RAG-ready transcripts (plain text + segments + SRT)
const transcriptRun = await client.actor('leopoldsaint/youtube-transcript-scraper').call({
    videoUrls,
    languages: ['en'],
    preferManualCaptions: true,
    includeSegments: true,
    includeSrt: false,
    skipUnavailable: true,
    maxTotalVideos: 10,
});
const { items: transcripts } = await client.dataset(transcriptRun.defaultDatasetId).listItems();

// 3. Mine viewer objections & tool requests from comments
const commentsRun = await client.actor('leopoldsaint/youtube-comments-scraper').call({
    videoUrls: videoUrls.slice(0, 5),
    sortBy: 'top',
    includeReplies: true,
    maxRepliesPerComment: 3,
    containsKeywords: ['pricing', 'alternative', 'issue', 'broken', 'wish'],
    maxTotalComments: 100,
});
const { items: comments } = await client.dataset(commentsRun.defaultDatasetId).listItems();

console.log({
    videosDiscovered: videos.length,
    transcriptsExtracted: transcripts.length,
    totalWords: transcripts.reduce((sum, t) => sum + (Number(t.wordCount) || 0), 0),
    objectionComments: comments.length,
});

Option 2: Python (Ready for LangChain / LlamaIndex / Vector DBs)

import os
from apify_client import ApifyClient

client = ApifyClient(os.environ["APIFY_TOKEN"])

# Pull transcripts directly from a playlist, channel @handle, or search query
run = client.actor("leopoldsaint/youtube-transcript-scraper").call(run_input={
    "videoUrls": ["@mkbhd"],
    "languages": ["en"],
    "includeSegments": False,
    "skipUnavailable": True,
    "maxVideosPerSource": 10,
    "maxTotalVideos": 10,
})

documents = []
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    documents.append({
        "id": item["videoId"],
        "title": item["title"],
        "channel": item["channelName"],
        "url": item["videoUrl"],
        "text": item["transcriptText"],
        "words": item["wordCount"],
    })

print(f"Loaded {len(documents)} transcripts ready for chunking & embedding.")

Option 3: 1-Node n8n or Make Automation (No Code)

Instead of polling run IDs across multiple steps, use Apify's synchronous endpoint inside a single n8n HTTP Request or Make HTTP module:

  • Method: POST
  • URL: https://api.apify.com/v2/acts/leopoldsaint~youtube-transcript-scraper/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN
  • Headers: Content-Type: application/json
  • Body:
{
    "searchQueries": ["n8n ai agent tutorial"],
    "languages": ["en"],
    "includeSegments": false,
    "skipUnavailable": true,
    "maxTotalVideos": 5
}

The node returns a clean JSON array of transcripts directly so you can pipe {{ $json.transcriptText }} straight into an OpenAI, Claude, or Gemini summarization node and post the digest to Slack or Notion.
